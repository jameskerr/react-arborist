# Package Manager Install Commands

Install `react-arborist` together with its drag-and-drop peer dependencies.

npm:

```bash
npm install react-arborist react-dnd react-dnd-html5-backend
```

yarn:

```bash
yarn add react-arborist react-dnd react-dnd-html5-backend
```

pnpm:

```bash
pnpm add react-arborist react-dnd react-dnd-html5-backend
```

The same dependency set keeps drag-and-drop behavior consistent across package managers.
